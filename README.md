# WeJJoy — 함께 쓰는 다이어리

**EnJJoy** 의 공유(네트워크) 버전입니다.
혼자 쓰던 다이어리를 **가족·친구와 실시간으로 함께** 쓸 수 있습니다.

- 다이어리 기능·디자인·위젯은 **EnJJoy 와 완전히 동일**합니다.
- 여기에 **공유 그룹**(관리자 1명 + 공유자 여러 명)이 더해졌습니다.
- 패키지 이름이 달라서 **EnJJoy 와 한 폰에 같이 설치**해도 서로 간섭하지 않습니다.

## 처음 시작하기 (순서대로)

### 1. 이 저장소를 깃허브에 올립니다
아래 **[파일 올리는 순서](#파일-올리는-순서)** 를 그대로 따라 하세요.

### 2. 공유 서버를 만듭니다 (관리자만, 한 번)
**[`파이어베이스-설정방법.md`](파이어베이스-설정방법.md)** 를 처음부터 끝까지 따라 하세요.
20~30분이면 끝나고, 전부 무료입니다.

> ⚠️ 이걸 건너뛰면 공유 기능만 꺼진 채로 **혼자 쓰는 다이어리**로 동작합니다.
> (앱이 고장 나는 게 아니니 나중에 하셔도 됩니다)

### 3. APK 를 받습니다
깃허브 저장소에서 **`Actions`** 탭 ▸ 맨 위 초록색 체크 ✅ 를 누르고
맨 아래 **`Artifacts`** 에서 **`WeJJoy-APK`** 를 내려받습니다. (5~10분 걸립니다)

### 4. 관리자가 그룹을 만듭니다
앱 ▸ **설정(톱니바퀴) ▸ 공유 그룹** ▸ 별명 입력 ▸ **`그룹 만들기`**
→ `WJ-ABC234` 같은 **초대 코드**가 나옵니다. **`코드 공유하기`** 로 상대에게 보냅니다.

### 5. 공유자가 참여합니다
같은 APK 설치 ▸ **설정 ▸ 공유 그룹** ▸ 별명 입력 ▸ 코드 넣고 **`참여하기`**
→ 끝. 이제부터 자동으로 함께 쓰입니다.

## 자주 궁금해하시는 것

**Q. EnJJoy 를 지워야 하나요?**
아니요. 둘은 서로 다른 앱으로 인식돼서 **같이 두고 쓸 수 있습니다.** 다만 두 앱의 기록은 따로입니다.

**Q. 공유자도 파이어베이스 설정을 해야 하나요?**
아니요. **관리자 한 사람만** 하면 됩니다. 공유자는 초대 코드만 넣으면 됩니다.

**Q. 관리자가 앱을 지우면 어떻게 되나요?**
서버의 기록은 남아 있고, 다른 공유자들끼리는 계속 공유됩니다.
다만 **'내보내기' 같은 관리 기능은 관리자만** 할 수 있으니, 관리자 폰은 유지하시는 게 좋습니다.

**Q. 같은 일정을 두 사람이 동시에 고치면?**
**나중에 고친 쪽**이 남습니다.

**Q. 돈이 드나요?**
아니요. 파이어베이스 무료 요금제(1GB 저장 / 월 10GB 전송)로 충분합니다.
글만 저장하므로 수십 년을 써도 남습니다.
(사진까지 공유하도록 선택하신 경우엔 Blaze 요금제로 바꿔야 하지만, 그 안에서도 매달 일정 용량까지는 무료 사용량이라 가족 단위로는 보통 0원입니다. 자세한 건 `파이어베이스-설정방법.md` 의 "사진도 같이 공유하기" 참고.)

**Q. 초대 코드가 새어 나가면?**
관리자가 그 사람을 **`해제`** 하면 다시 못 들어옵니다.
정말 걱정되면 관리자가 그룹을 새로 만들고 새 코드를 나눠주면 됩니다.

## 앱을 고칠 때 (업데이트 방법)

1. 깃허브에서 고칠 파일을 열고 **연필(✏️)** 을 눌러 고칩니다.
2. **`Commit changes`** 를 누릅니다.
3. `Actions` 탭에서 자동 빌드가 끝나면 새 APK 를 받아 **덮어 설치**합니다.

> 서명키(`debug-keystore.b64`)가 저장소에 고정되어 있어서
> **기존 앱 위에 그대로 업데이트 설치**됩니다. 기록이 지워지지 않습니다.
> 이 파일은 절대 지우지 마세요.

## 만든 것들 (기술 메모)

| 위치 | 내용 |
|---|---|
| `sync/FirebaseConfig.kt` | 파이어베이스 값 4개(+사진 공유용 Storage 버킷 1개, 선택). **필수 4개만 채우면 공유가 켜집니다** |
| `sync/SyncManager.kt` | 그룹 만들기·참여·내보내기, 실시간 주고받기, (선택) 사진 업로드·다운로드 |
| `ui/GroupActivity.kt` | 공유 그룹 화면 |
| `util/LunarCalendar.kt` | 음력 변환표 (1900~2049, 한국천문연구원 기준) |
| `util/KoreanHolidays.kt` | 공휴일·대체공휴일·기념일 |
| `util/Palette.kt` | 디자인 8색 × 밝은/어두운 |
| `widget/` | 월·주·일 위젯 |

- 최소 안드로이드 8.0 (API 26) / 대상 14 (API 34)
- 저장: Room (폰 안) + Firebase Realtime Database (공유분만) + (선택) Firebase Storage (사진 공유 시)
- 로그인: 익명 로그인 — 아이디·비밀번호를 만들 필요가 없습니다
